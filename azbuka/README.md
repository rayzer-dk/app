# Азбука приключений — 0.7.0

Воспроизводимое обновление исходного архива 0.6.2. Учебная программа, курс письма, аудио и локальные профили сохраняются. Новые функции: отключаемые анимации, интерактивный счёт, предложение установки PWA, ручная проверка обновлений.

Для сборки распакуйте исходный архив 0.6.2 в отдельную папку, выполните `python3 azbuka/upgrade.py ПАПКА` и `python3 azbuka/verify.py ПАПКА`. Обновлённая папка готова для размещения на статическом HTTPS-сайте. Для установки PWA на компьютере также подходит localhost.

Полный ZIP отсутствует в репозитории. Для запуска полной проверки GitHub Actions добавьте в корень исходный архив с именем Azbuka_Adventure_Server_v0.6.2.zip или собранный Azbuka_Adventure_Server_v0.7.0.zip. При отсутствии архива проверка приложения намеренно завершается ошибкой. Остальные приложения не изменены.

Локально проверено: JS-синтаксис, учебные данные, счёт и экспорт/импорт профилей в Node VM, 73 ресурса кеша, 1679 аудиофайлов и 23 аудиопакета. Реальная установка PWA и воспроизведение аудио пока не подтверждены.

Для загрузки через веб-интерфейс GitHub можно вместо большого ZIP добавить сразу три файла Azbuka_Adventure_Server_v0.7.0.zip.part01, .part02 и .part03 в корень репозитория. Workflow объединит их, сверит SHA-256 и проверит приложение. Дополнительно настроен браузерный тест Chromium (адаптивность, счёт, письмо и перезапуск в офлайн-режиме). Этот тест ещё не выполнялся на GitHub.
