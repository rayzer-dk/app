# Лукоморье 1.10.0

Сборка из проверенного архива 1.8.2 и точного патча 1.8.4. Включены 412 произведений, интерактивные полки, локальные книги и прогресс, отдельные тексты и управление анимациями. Основные исходники восстанавливаются в src/ с проверкой контрольных сумм; восемь новых книг импортируются при сборке из закреплённых ревизий Викитеки; исходный архив сохраняется в корне репозитория.

Требуется Node.js 22.12+ (CI использует 24) и Python 3.

В папке lukomorye:
```sh
npm install
python3 -m pip install beautifulsoup4==4.14.3
npm run prepare:source
npm run build
npm test
npx playwright install chromium
npm run test:browser
```

Vite собирает серверную PWA и автономный классический IIFE-скрипт для file://. Официальные SVG Lucide включаются локально на этапе сборки, без CDN. Workbox отвечает за маршрутизацию service worker; строгая SHA-256 проверка каждого ресурса и атомарная установка полного кеша сохранены. Vitest проверяет целостность обеих сборок. Playwright проверяет мобильный/настольный интерфейс и чтение без сети.

dist/server — для HTTPS-хостинга, dist/offline — распаковать и открыть index.html. Никаких npm/CDN-зависимостей при чтении. Не удаляйте прежний архив: он является проверенной базой для воспроизводимой сборки.

GitHub Actions создаёт оба ZIP только после успешной сборки и тестов. Исходная версия сайта не меняется автоматически.

Версия 1.10.0: локальные тематические векторные иллюстрации, два режима каталога, случайная книга из текущей подборки, компактная мобильная шапка, точечное обновление избранного. Иллюстрации декоративные, не издательские обложки.

Версия 1.10.0: восемь новых классических произведений, редакционные аннотации, явно отмеченные начальные фрагменты вместо технических описаний, тематические подборки. Новые исторические издания проверяются по идентификатору ревизии, длине, наличию финала и глав; тексты полностью включаются в обе сборки. Источники и контрольные суммы — CONTENT_REVIEW.json. Два исторических перевода сохраняют дореформенную орфографию. Подборка «Лучшее» редакционная, не статистика пользователей.
