# Лукоморье 1.15.0

Сборка из проверенного архива 1.8.2 и точного патча 1.8.4. Включены 433 произведения, интерактивные полки, локальные книги и прогресс, отдельные тексты и управление анимациями. Основные исходники восстанавливаются в src/ с проверкой контрольных сумм; двенадцать новых книг импортируются при сборке из закреплённых ревизий Викитеки; исходный архив сохраняется в корне репозитория.

Требуется Node.js 22.12+ (CI использует 24) и Python 3.

В папке lukomorye:
```sh
npm install
python3 -m pip install beautifulsoup4==4.14.3
npm run prepare:source
npm run build
npm test
npx playwright install chromium
npm run test:browser
```

Vite собирает серверную PWA и автономный классический IIFE-скрипт для file://. Официальные SVG Lucide включаются локально на этапе сборки, без CDN. Workbox отвечает за маршрутизацию service worker; строгая SHA-256 проверка каждого ресурса и атомарная установка полного кеша сохранены. Vitest проверяет целостность обеих сборок. Playwright проверяет мобильный/настольный интерфейс и чтение без сети.

dist/server — для HTTPS-хостинга, dist/offline — распаковать и открыть index.html. Никаких npm/CDN-зависимостей при чтении. Не удаляйте прежний архив: он является проверенной базой для воспроизводимой сборки.

GitHub Actions создаёт оба ZIP только после успешной сборки и тестов. Исходная версия сайта не меняется автоматически.

Версия 1.15.0: локальные тематические векторные иллюстрации, два режима каталога, случайная книга из текущей подборки, компактная мобильная шапка, точечное обновление избранного. Иллюстрации декоративные, не издательские обложки.

Версия 1.15.0: восемь новых классических произведений, редакционные аннотации, явно отмеченные начальные фрагменты вместо технических описаний, тематические подборки. Новые исторические издания проверяются по идентификатору ревизии, длине, наличию финала и глав; тексты полностью включаются в обе сборки. Источники и контрольные суммы — CONTENT_REVIEW.json. Два исторических перевода сохраняют дореформенную орфографию. Подборка «Лучшее» редакционная, не статистика пользователей.

Версия 1.15.0: до 100 закладок в книге, сохраняемых в существующей резервной копии прогресса; активная глава в оглавлении; таймер сна для Web Speech API; локальные рекомендации похожих книг. Срок таймера действует только при озвучивании; фактическое воспроизведение зависит от голосов устройства. Состав библиотеки не изменён.

Версия 1.15.0: четыре классических произведения (Жюль Верн и Б. Житков), дополнительные сюжетные SVG-иллюстрации для популярных книг, жанровые цветовые палитры и визуальные снимки каталога/читалки для 320, 390, 768 и 1440 px. Снимки не являются автоматическим подтверждением художественного качества. Все новые произведения встроены в архивы после проверки импорта.

Версия 1.15.0: исправлено перекрытие кнопки избранного; четыре интерактивные иллюстрированные подборки, четыре исторические иллюстрации Билибина, Тенниела, Дюлака и Риу, сохранённые в WebP с источниками, SHA-1 исходников и SHA-256 готовых ресурсов. Изображения не вставляются в текст чтения; SVG остаётся резервом. Источники — art/credits.json. Для сборки требуется Pillow 12.0.0.

Версия 1.15.0: мобильная панель дополнительных фильтров сворачивается, счётчик учитывает активные фильтры и сортировку, компактный индикатор полной офлайн-доступности. Четыре дополнительные исторические иллюстрации Билибина и Васнецова, всего восемь. Содержание библиотеки не менялось (416 произведений).

Версия 1.15.0: 17 авторских сказок Гауфа, Андерсена, Уайльда и Чарской, русские тексты в проверяемых редакциях, аннотации, возрастные пометки и тематические подборки. Суммарно 433 произведения. Для текстов Уайльда в современной электронной редакции сохранена информация об источнике и лицензии. Регрессионный тест закладок проверяет фактическое сохранение в localStorage и завершение перехода истории перед перезагрузкой.

Версия 1.14.0: локальная сказка дня из подходящих произведений, автопрокрутка с четырьмя скоростями и ручной остановкой, необязательная иллюстрация в начале книги, история приблизительного активного времени чтения за последние семь дней (локальные записи до 90 дней на книгу, экспорт вместе с прогрессом). Улучшено восстановление режима каталога, учёт прогресса в границах самого текста и остановка прокрутки при уходе из читалки. Состав библиотеки сохранён: 433 произведения. История времени не является точным измерением внимания читателя.

Для автономного file:// режима добавлены резервные копии настроек, избранного и прогресса в sessionStorage и IndexedDB (без удаления существующих книг), ограниченный снимок состояния в истории для перезагрузки вкладки. В браузерах с запретом постоянного локального хранилища перенос прогресса по-прежнему требует экспорта. Тест намеренно удаляет основные записи localStorage перед перезагрузкой, затем проверяет восстановление режима каталога и закладок.

Версия 1.15.0: подборка из 40 кандидатов для пополнения классическими сказками; в сборку включаются только прошедшие проверку произведения. CONTENT_REVIEW.json содержит принятые и исключённые тексты, даты редакций, источники и контрольные суммы. Добавлены 44 редакционные аннотации к прежним сказкам, три исторических рисунка Педерсена и опциональное перелистывание экранов текста кнопками или клавишами. Это режим экранных страниц с сохранением непрерывного текста и закладок, не имитация бумажного листа. Индивидуальная вычитка всех новых текстов ещё требуется.

Исправлена проверка фактического числа книг вместо устаревшей константы 433. Для двух произведений Уайльда указаны непосредственно проверенные редакции 1908 года и конечные фразы. Добавлены ещё 14 аннотаций к существующим произведениям Андерсена. Редакционная вычитка остаётся отдельной задачей.

Финальный состав 1.15.0 зафиксирован: 457 произведений, в том числе 24 принятых текста последнего пополнения. Для каждого из них закреплена ревизия и точное число слов; оставшиеся 16 кандидатов исключены. При недоступности источника сборка завершается ошибкой, а не выпускает урезанную библиотеку. Новые произведения не добавляются. Повторные запросы учитывают Retry-After.

Версия 1.16.0: «Сказки из нашего детства» — 86 произведения, 17 новых самостоятельных русских пересказов традиционных украинских, белорусских и русских сюжетов. Не копии сценариев мультфильмов и не исторические переводы. Существующие 69 произведений включены в подборку без дублирования. Общее число книг: 474. Варианты названий Жихарка, Вершки и корешки, Заюшкина избушка добавлены как поисковые псевдонимы.

1.16.1: пять сокращённых пересказов заменены полными переводами конкретных украинских фольклорных записей; исходные ID сохранены, ревизии текста повышены, указаны ссылки и лицензии. 12 пересказов ещё требуют замены. TEXT_AUDIT.json содержит структурный аудит всех 474 текстов; короткий объём сам по себе не означает сокращение. Полная сверка всех старых изданий не выполнена.

1.16.2: ещё два перевода украинских записей («Коза-дереза», «Кривенькая уточка»), всего семь замен. Десять сокращённых пересказов остаются обозначенными. Новый единый HTML содержит все 474 книги, стили, JavaScript, логотип и иллюстрации; он не требует доступа к соседним файлам. Android-провайдер может ограничивать хранение данных или запуск скриптов; для установки PWA нужна HTTPS-версия. Автоматические тесты моделируют недоступность сети и соседних файлов, а не физическое устройство OnePlus.
