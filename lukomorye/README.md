# Лукоморье 1.8.5

Сборка из проверенного архива 1.8.2 и точного патча 1.8.4. Включены 404 произведения, интерактивные полки, локальные книги и прогресс, отдельные тексты и управление анимациями. Исходники восстанавливаются в src/ без сети с проверкой контрольных сумм; исходный архив сохраняется в корне репозитория.

Требуется Node.js 22.12+ (CI использует 24) и Python 3.

В папке lukomorye:
```sh
npm install
npm run prepare:source
npm run build
npm test
npx playwright install chromium
npm run test:browser
```

Vite собирает серверную PWA и автономный классический IIFE-скрипт для file://. Официальные SVG Lucide включаются локально на этапе сборки, без CDN. Workbox отвечает за маршрутизацию service worker; строгая SHA-256 проверка каждого ресурса и атомарная установка полного кеша сохранены. Vitest проверяет целостность обеих сборок. Playwright проверяет мобильный/настольный интерфейс и чтение без сети.

dist/server — для HTTPS-хостинга, dist/offline — распаковать и открыть index.html. Никаких npm/CDN-зависимостей при чтении. Не удаляйте прежний архив: он является проверенной базой для воспроизводимой сборки.

GitHub Actions создаёт оба ZIP только после успешной сборки и тестов. Исходная версия сайта не меняется автоматически.
